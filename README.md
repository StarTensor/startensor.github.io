# startensor.github.io

My personal homepage — a GitHub dark-themed profile page built with vanilla HTML/CSS/JS.

## ✨ Features

- **GitHub Profile Layout** — faithful recreation of GitHub's user profile UI
- **Dark Theme** — CSS variable-driven, matches GitHub Dark Mode colors
- **Live2D Mascot** — interactive character with model switching, hitokoto quotes, and more
- **Matrix Code Rain** — Canvas animation with katakana + hex characters
- **Particle Background** — floating particles with connecting lines
- **Contribution Heatmap** — 28-week GitHub-style activity grid
- **Typing Effect** — rotating taglines in the sidebar
- **Repository Search** — filter repos with keyboard shortcuts
- **Responsive** — adapts from desktop to mobile (4 breakpoints)
- **BGM Player** — background music with toggle control

## 🛠 Tech Stack

| Layer | Technology |
|-------|------------|
| Structure | HTML5, semantic tags |
| Styling | CSS3, CSS Grid + Flexbox, CSS Variables |
| Animation | Canvas API, requestAnimationFrame |
| Interactivity | Vanilla JavaScript (ES6+) |
| Live2D | Cubism 2.1 Core via jsDelivr CDN |
